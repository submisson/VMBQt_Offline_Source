# Third-party software

The original VMBQt source in this archive is licensed under MIT (see ../LICENSE).
No TIER IV webpage source, brand assets, or cloud server code is included.

Dependencies are installed separately by pip and apt and retain their own terms:

| Dependency | Role | Project / license information |
|---|---|---|
| Qt / PySide6 / Shiboken6 | Native GUI and rendering | https://doc.qt.io/qtforpython-6/ — LGPLv3/GPLv3/commercial licensing; consult the actual distribution |
| NumPy | Numeric geometry and cloud projection | https://numpy.org/ — BSD-3-Clause |
| pyproj / PROJ | Coordinate conversion | https://pyproj4.github.io/pyproj/ — MIT; PROJ and bundled data have their own notices |
| PyYAML | Projection/metadata YAML | https://pyyaml.org/ — MIT |
| pytest | Optional tests | https://pytest.org/ — MIT |
| Lanelet2 | Optional real-reader interoperability tests | https://github.com/fzi-forschungszentrum-informatik/Lanelet2 — BSD-3-Clause |

The archive contains no dependency wheels or external font files. Install Ubuntu
fonts-noto-cjk for the Chinese UI. The PCD, OSM and CSV examples are generated by
tools/create_demo.py and contain artificial data, not a surveyed road map.
