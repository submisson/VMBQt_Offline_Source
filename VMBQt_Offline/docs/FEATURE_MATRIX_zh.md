# 功能对照与明确差异

核对日期：2026-10-26。对照依据是公开的 VMB 画面结构、简介、Autoware 地图教程与格式说明，**不是登录当前账号后的逐项验收结果**。不同账号、服务版本、FMS 套餐的实际功能可能不同。本表不能作为“网页版所有功能已实现”的声明。

状态定义：**已实现**表示当前源码有可调用的实际实现；**部分**表示范围、算法、性能或工作流与 VMB 有差异；**通用编辑**只表示能保存并编辑数据结构，不表示有对应的一键工具或完整语义检查；**未实现**表示不提供该功能。

## 文件和工程

| 功能 | 状态 | 本工程入口 / 差异 |
|---|---|---|
| 原生 Ubuntu Qt 窗口 | 已实现 | Qt 6 / PySide6 Widgets；Python 源码，不是 C++ |
| 新建/保存/打开工程 | 已实现 | `.vmbqt`，含图元与资源引用 |
| 保存时原子替换 | 已实现 | 同目录临时文件 + fsync + rename |
| 撤销/重做 | 已实现 | 几何事务，60 步及约 96MiB 预算；资源导入不在历史内 |
| 崩溃恢复文件 | 已实现 | 每分钟写一次，启动可恢复 |
| PCD ASCII / binary | 已实现 | 后台读取，每文件显示样本最多 300k |
| PCD binary_compressed | 已实现 | PCL field-major + LZF；512MiB 解压上限 |
| 多文件/目录加载 PCD | 已实现 | 目录只查当前层；逐文件后台读取 |
| PCD 原始数据修改/重新编码 | 未实现 | 不提供点云编辑器；地图目录导出复制完整原文件 |
| PCD metadata 读取/编辑/导出 | 部分 | 原结构 YAML 编辑；不从采样点重算分块边界 |
| Lanelet2 OSM 导入/导出 | 已实现 | node/way/relation，显式坐标投影 |
| 原 ID 和未知标签/关系保留 | 已实现 | 不删除未知图元；按类型区分相同 ID |
| 完全保持原 XML 字节 | 未实现 | 重排缩进与标签；不保留注释；Local 重写 lat/lon |
| MapMetaInfo | 已实现 | 字符串属性 JSON 编辑，保留其他根扩展 |
| 旧验证签名失效处理 | 已实现 | 修改后移除旧 `<validation>` |
| 合并多地图 | 部分 | 文件导入并重分配 ID；要求统一投影，不自动跨坐标系合并 |
| Map Projector Info YAML | 部分 | Local / MGRS / LocalCartesianUTM / TransverseMercator |
| LocalCartesian ENU | 未实现 | 不等同 LocalCartesianUTM；不接受该类型冒充支持 |
| Map Config 的旧版专用导出 | 未实现 | 仅导出当前明确支持的 map_projector_info.yaml |
| EGM2008 / 高程转换 | 未实现 | 非 WGS84 的投影声明会被拒绝 |
| MGRS 跨 100km 方格 | 未实现 | 明确检查越界 |
| 轨迹/停靠点 CSV | 部分 | 本地 x/y/z/yaw 表头；保留附加列，未验收所有 FMS CSV |
| PNG 导出 | 已实现 | 当前画布截图 |
| Autoware 地图目录 | 部分 | OSM、投影、完整 PCD、输入的 metadata；需目标系统验收 |

## 道路和规则

| 功能 | 状态 | 本工程入口 / 差异 |
|---|---|---|
| 中心线绘制生成左右边界 | 已实现 | 车道宽与限速默认值 |
| 两条边界创建 Lanelet | 已实现 | 按先左后右选择 |
| 增加邻道并共享边界 | 已实现 | 生成同向邻道 |
| 任意复杂对向共享边界编辑 | 部分 | 可以编辑关系；反向快捷操作会阻止破坏未选共享对象 |
| 更改宽度/方向 | 部分 | 有共享边界或外部引用时受保护，不提供全部传播策略 |
| 端点拓扑连接 | 已实现 | 合并对应点 ID，受距离阈值限制 |
| 车道拆分/合并 | 部分 | 独立边界支持；规则迁移/外部引用有保护限制 |
| 中心线生成 | 部分 | 等弧长配对取中点；不是 Autoware 优化路径 |
| 转弯连接/交叉口批量连接 | 部分 | 显式勾选入/出组合，三次 Bézier；非 VMB 恒曲率算法 |
| 道路肩/人行道/自行车道等 subtype | 通用编辑 | 修改 Lanelet 标签；无逐类型专用向导 |
| 停止线与停止标志 | 已实现 | 一键初始几何；需调到真实位置 |
| 信号灯外框/灯泡/停止线 | 已实现 | 初始几何可编辑；color/traffic_light_id/height |
| 人行横道/关联规则 | 已实现 | 先画 crosswalk Lanelet，再关联道路 |
| Crosswalk Polygon/可选停止线 | 通用编辑 | 在规则成员中添加 crosswalk_polygon/ref_line |
| 检测区域 / 禁停 / 禁泊 / 减速带 | 已实现 | Polygon + 对应规则 + 车道关联 |
| 路权 right_of_way | 已实现 | 两车道快捷关联；更多成员用属性表 |
| Virtual Traffic Light / Bus Stop | 通用编辑 | subtype 与成员可保存；无等价一键配套几何生成 |
| Road Marking / All Way Stop / 自定义规则 | 通用编辑 | 任意 OSM 规则结构；未覆盖所有语义约束 |
| 换道允许、虚线/实线 | 已实现 | 边界标签快捷设置 |
| FMS 可通行标签 | 通用编辑 | 可设置 fms_lane_passable；无云端路径服务 |
| Fit to PCD | 部分 | 已加载可见点云样本的 XY 最近点，受搜索半径限制 |
| Trajectory 转 Lanelet | 已实现 | 按线性 CSV 行序，选择区间和采样间距 |
| Trajectory Point 的分支图 | 未实现 | 只支持线性点序列及 lanelet_id 列 |
| 停靠点位置、方向、名称 | 部分 | 投到中心线后编辑；本地 CSV，与 FMS 版本格式需映射 |

## 达到“全部功能一致”还需要什么

需要先冻结被验收的 VMB 版本与账号功能，逐项录制输入/输出和异常处理，补充 FMS/Autoware 的真实接口、地图集和需求集，再实现未覆盖的工作流、投影与高程、GPU 大点云架构和完整规则验证。在当前交付中，这些部分没有被声明完成。
